# Peiling Studio

Public portfolio hub for Pei Ling Hsu. Static HTML, CSS, JavaScript. No accounts, backend, analytics, or submitted form data.

## Update projects

- Add a project card in `index.html`, matching `data-category` for the filter.
- Add case copy and the public project URL in `main.js` (`cases`).
- Store public preview images under `assets/`. Never copy account records or private screenshots.
- Keep contact details absent until the owner supplies a public business contact.

The brief form downloads a text file locally. It does not contact Peiling or transmit data.

YGM is currently a case study only. The actual development interface remains in the parent workspace and is not included in this public repository.
